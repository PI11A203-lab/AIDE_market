# 학생증 인증 이미지 폴더

이 폴더에 **학생증 신청 시 업로드되는 이미지** (학생증 사진, 인증 서류 등)를 넣어주세요.

## Mock 데이터용 이미지 (개발/데모용)

Super Admin의 **학생 인증** 페이지에서 Mock 데이터를 사용할 때 다음 파일명으로 이미지를 넣어주시면 됩니다:

- `sample-student-id.jpg` 또는
- `sample-student-id.png`

**경로 예시:**
```
public/images/student-verifications/sample-student-id.jpg
```

위 파일을 이 폴더에 추가하면, 학생 인증 목록에서 "문서 보기"를 클릭했을 때 해당 이미지가 표시됩니다.

> 참고: 실제 운영 시에는 사용자가 업로드한 이미지가 백엔드 서버에 저장되며, 이 폴더는 개발/테스트용 Mock 데이터 표시에만 사용됩니다.
