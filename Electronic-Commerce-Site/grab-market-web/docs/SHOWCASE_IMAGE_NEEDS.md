# 프로젝트 탭(쇼케이스) 이미지 필요 목록

상품 상세 페이지 **프로젝트** 탭에서 데모/예시로 쓸 이미지·에셋을 카테고리·유형별로 정리했습니다.  
준비 시 참고용으로 사용하세요.

---

## 1. 이미지·디자인 생성 (category: image)

| 유형 | 상품 예시 | 필요한 이미지/에셋 |
|------|-----------|---------------------|
| **일러스트** | Artelia | AI가 생성한 일러스트 예시 2~3장 (다양한 스타일) |
| **도트/픽셀아트** | Pixelbit | 도트 캐릭터·타일 예시, 게임 스프라이트 느낌 |
| **풍경** | Scenerya | 풍경화·배경 이미지 예시 (자연, 도시 등) |
| **3D 모델** | Modelia | 3D 모델 미리보기(캐릭터/오브젝트/환경), 또는 랜더 이미지 1~2장 |
| **애니메이션** | Animotion | 짧은 GIF 또는 프레임 시트 예시 (모션 결과물) |
| **로고·브랜딩** | LogoForge | 로고/브랜드 예시 2~3종 (타입·마크 조합) |
| **캐릭터 디자인** | CharaDesign | 캐릭터 시트·표정/포즈 변형 예시 |
| **UI/UX** | UIUXGen | 화면 목업·와이어프레임·UI 컴포넌트 예시 |
| **아이콘** | IconMaker | 앱/웹용 아이콘 세트 예시 (16px~64px) |
| **텍스처** | TexturePro | 3D용 텍스처(나무, 금속, 천 등) 타일 예시 |
| **AI 이미지(전문)** | MidjourneyAI, DALLEMaster | 프롬프트→출력 이미지 예시 1~2세트 |

---

## 2. 프론트엔드 (category: frontend)

| 유형 | 필요한 이미지/에셋 |
|------|---------------------|
| **공통** | 코드 에디터 스크린샷(구문 강조), 또는 컴포넌트 트리/앱 미리보기 화면 1장 |
| **선택** | React/Vue/Next 등으로 만든 간단한 화면 캡처(대시보드, 폼, 리스트 중 1종) |

→ 데모는 **예시 코드 + 결과 파일명** 위주로 두고, 이미지는 “실행 결과 화면” 1장만 있어도 충분합니다.

---

## 3. 백엔드 (category: backend)

| 유형 | 필요한 이미지/에셋 |
|------|---------------------|
| **공통** | API 코드 스니펫 스크린샷, 또는 터미널에서 `curl`/응답 JSON 캡처 |
| **선택** | Swagger/Postman 같은 API 문서 화면 1장 |

→ 데모는 **예시 코드 + 응답(JSON/로그)** 위주. 이미지는 “API 문서/실행 결과” 1장이면 됩니다.

---

## 4. 관리·기획 (category: management)

| 유형 | 필요한 이미지/에셋 |
|------|---------------------|
| **공통** | 태스크 보드·간트·요구사항 목록 등 툴 UI 캡처 1장 |
| **선택** | 생성된 문서(PRD, 스펙 요약) 미리보기 1장 |

→ “이 AI가 만들어 주는 결과물”을 보여주는 문서/대시보드 스크린샷 위주.

---

## 5. 인프라·DevOps (category: infrastructure)

| 유형 | 필요한 이미지/에셋 |
|------|---------------------|
| **공통** | Docker/K8s/AWS 등 설정 파일 스니펫, 또는 아키텍처 다이어그램 1장 |
| **선택** | 파이프라인 성공 화면, 대시보드(모니터링) 캡처 1장 |

→ **예시 코드/설정 + 다이어그램 또는 대시보드** 조합이면 충분합니다.

---

## 6. 보안 (category: security)

| 유형 | 필요한 이미지/에셋 |
|------|---------------------|
| **공통** | 스캔 결과 요약, 정책/룰 스니펫, 또는 대시보드(알람·이벤트) 1장 |
| **선택** | 리포트/컴플라이언스 체크리스트 미리보기 |

→ **예시 출력(텍스트/표) + 결과 화면** 1장 정도.

---

## 7. 문서·오피스 (category: documents)

| 유형 | 필요한 이미지/에셋 |
|------|---------------------|
| **Excel** | SheetBot | 차트·피벗이 포함된 시트 미리보기 1장 |
| **PowerPoint** | SlideMind | 슬라이드 1~2장(레이아웃 예시) |
| **문서/Word** | DocWriter | 생성된 문서 첫 페이지 미리보기 |
| **Notion/Confluence** | NotiFlow, ConfluenceDoc | 페이지·테이블 미리보기 |
| **API 문서** | APIDocGen, SwaggerPro | OpenAPI/Swagger UI 화면 1장 |
| **Markdown/기술문서** | MarkdownMaster, TechWriter | 생성된 MD/문서 조각 스크린샷 |
| **Figma 문서** | FigmaDoc | Figma 내 스펙/문서 화면 1장 |

→ “이 AI가 만들어 주는 문서/스프레드/슬라이드” 결과물 1장씩 있으면 좋습니다.

---

## 요약: 이미지 유형별 체크리스트

- **3D**  
  - 랜더 이미지 또는 간단한 3D 뷰어 스크린샷 (Modelia 등)
- **풍경/배경**  
  - Scenerya 등 풍경 생성 결과 1~2장
- **일러스트/캐릭터/도트**  
  - Artelia, CharaDesign, Pixelbit 등 스타일별 출력 예시
- **로고/아이콘/UI**  
  - LogoForge, IconMaker, UIUXGen 결과물 1세트
- **텍스처**  
  - TexturePro 타일/패턴 예시
- **애니메이션**  
  - Animotion GIF 또는 프레임 시트
- **코드/API/인프라**  
  - 에디터·터미널·API 문서·다이어그램 캡처 (실행 결과 위주)
- **문서/스프레드/슬라이드**  
  - Excel/PowerPoint/Word/Notion/API 문서 화면 1장

이미지가 없어도 **예시 코드 + 결과 텍스트**만으로 데모는 동작하도록 구현해 두었습니다.  
이미지는 준비되는 대로 교체·추가하시면 됩니다.
